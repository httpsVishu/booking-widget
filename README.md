# Fig Booking Intake

AI-powered booking intake system for local service businesses.

## Stack
- Frontend: Vite + Vanilla JS + Tailwind CSS + Motion One
- Backend: Node.js + Express
- Storage: Local JSON
- AI: OpenAI API

## Setup

### Backend
cd backend
cp ../.env.example .env
# Add your OPENAI_API_KEY
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev

## Deploy
- Frontend → Vercel
- Backend → Render
